0.40	Verschiedene Gleichungen geben verschiedene Graphen. Die einfachste kennst du: y gleich x, eine Gerade durch den Nullpunkt. Wird x um eins grösser, wird auch y um eins grösser.
12.25	y gleich x Quadrat. Für x gleich zwei kommt vier heraus, für minus zwei auch vier. Der Graph ist symmetrisch zur y-Achse, hat unten einen Scheitel und wird nach aussen immer steiler. Das ist eine Parabel.
25.48	y gleich Wurzel aus x. Wurzel aus eins ist eins, Wurzel aus vier ist zwei. Der Graph beginnt im Nullpunkt und wird immer flacher. Links von der y-Achse gibt es keine Punkte: Aus negativen Zahlen gibt es keine Wurzel.
39.65	y gleich eins durch x. Für x gleich eins kommt eins heraus, für x gleich zwei null Komma fünf, und für x gleich null Komma fünf kommt zwei heraus. Bei null gibt es keinen Wert. Der Graph hat zwei Äste und trifft keine Achse.
57.49	Wurzel aus neun ist drei, Wurzel aus sechzehn ist vier: Das passt zu y gleich Wurzel aus x. Die Gerade y gleich x durch drei trifft nur den ersten Punkt.
67.71	Mit Testpunkten ordnest du zu. Setz zum Beispiel x gleich vier ein: Die Gerade gibt vier, die Parabel sechzehn, die Wurzel zwei, der Kehrwert null Komma zwei fünf. Und x gleich null oder eine negative Zahl zeigt, wo es gar keinen Wert gibt.
82.76	Eine Zahl davor streckt den Graphen. Zwei x Quadrat ist doppelt so hoch wie x Quadrat. Mit einem Minus davor kippt die Parabel nach unten.
91.75	Häufiger Fehler: zu wenige Punkte. Null, null und eins, eins liegen auf der Geraden und auf der Parabel. Erst x gleich zwei trennt die beiden: zwei gegen vier.
102.00	Zum Mitnehmen: Gerade, Parabel, Wurzel- und Kehrwertgraph erkennst du an der Form. Zum Zuordnen setzt du Testpunkte ein, auch x gleich null und eine negative Zahl.
